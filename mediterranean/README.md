# Mediterranean · 地中海

面向 iPhone 主屏幕 PWA 的中文菜谱应用，统一使用手机布局。纯静态文件，无需安装依赖或执行构建即可发布。

## 这一版包含

- 从用户提供的 HTML 迁移 40 道菜：12 道早餐、14 道午餐、14 道晚餐。
- 六类图片导航：蛋奶轻食、谷物主食、肉禽料理、鱼虾海鲜、蔬菜豆类、暖汤炖菜。
- 按菜名及食材搜索；移除餐次、用时和做法筛选，分类列表直接看图选菜。
- 菜卡与详情不展示预计总耗时，保留操作步骤中必要的时间。
- 每道菜独立配图、原稿食材及用量、准备、步骤；操作提示和完成检查点融入对应步骤。
- 收藏、最近浏览、分步烹饪和进度恢复、步骤参考计时。
- 可选食材库、优先使用标记、现有食材匹配；不登记食材也能完整使用。
- 分类列表优先展示契合度高的菜，详情自动用绿色勾显示已有、暖红色显示缺少。
- 详情食材区默认展开，点击标题行即可收起；收起时保留已有／缺少数量，本次使用期间按菜谱记住折叠状态。
- 缺料采购、同类食材集中展示、已购勾选；右上角加号补充食材，更多菜单统一管理入库、清理与撤销。
- 本机保存、JSON 备份与恢复、浅色及深色模式。
- PWA 图标、完整缓存后的离线使用和更新提示。

## 预览

双击 index.html 可体验基本页面；离线缓存及 PWA 安装需要本地 HTTP 或线上 HTTPS。

本次制作提供的本地预览地址为 `http://127.0.0.1:4173/`，只在当前电脑可访问，需保持预览服务运行。

如需自行启动，可在本文件所在文件夹使用已有 Python 运行：

```text
python -m http.server 4173 --bind 127.0.0.1
```

## 手动上传 GitHub Pages

1. 在 GitHub 创建仓库，例如 mediterranean。
2. 将本文件夹里的发布文件上传到仓库根目录，确保 index.html 位于根目录。
3. 必须包含 assets 文件夹及所有 JS、CSS、JSON、webmanifest 文件，建议一并保留 .nojekyll。
4. README.md 和 AGENTS.md 可保留；过程脚本、旧截图和测试备份已清理，无需上传。
5. 仓库 Settings → Pages，选择 Deploy from a branch，分支选择 main，目录选择 /(root)，然后保存。
6. 等待 GitHub 显示实际发布地址后，用 Safari 打开。一般地址形如 https://你的用户名.github.io/mediterranean/。

如果保留整个 mediterranean 文件夹作为更大仓库中的子目录，也可以在对应发布地址后追加 /mediterranean/ 访问；所有资源和离线范围都使用相对路径。

## iPhone 主屏幕使用

1. 在 Safari 打开实际发布的 HTTPS 地址。
2. 分享 → 添加到主屏幕，按系统提示作为网页 App 打开。
3. 从新图标打开，首次保持联网，在设置中确认“离线就绪”。
4. 完成缓存后可离线浏览和使用主要功能。

桌面浏览器模拟不能代替真实 iPhone 验证。锁屏及后台不保证计时响铃，返回应用时按截止时间恢复状态。

## 图片与菜谱说明

40 张配图使用用户在“地中海厨房图片”目录提供的独立 PNG，按 01–40 编号逐一对应。
原始素材未修改；发布文件转换为高质量 WebP，保留 1448×1086 分辨率，合计约 15.1 MB。图片路径按菜谱 id 固定，替换不影响收藏和个人数据。
每道菜的食材和全部原稿烹饪操作均保留；将原文连续的短步骤按顺序合并为更适合手机阅读的段落，没有删除操作。
步骤时间、用量及检查点沿用原稿，不新增热量或营养计算。原稿引用信息保存在数据中，界面移除来源、搭配与补救说明折叠区。
分步模式中的“备料用量”指菜谱原定总用量，不代表该步独立分配用量；可随时打开完整食材表。

## 数据与更新

个人数据仅保存在当前浏览器/主屏幕应用，不自动跨设备同步。系统或用户清理网站数据可能移除记录，请定期导出备份。
食材匹配以种类为依据；“食材已齐”不表示数量足够。熟豆、生毛豆和熟毛豆等保持区分，常备调料需要自己选择。
采购清单不猜测不同单位的换算，同类食材按来源分别保留用量。购买后需主动点“将已购食材入库”。

修改页面、数据或图片后，一并修改 sw.js 中的 VERSION，上传完整更新。
应用检测到更新后会提示，用户操作后才切换，不在烹饪中强制刷新。

## 扩充菜品库

菜谱数据在 recipes.js；每道菜使用稳定 id，图片在 assets/recipes，分类与原料字典也随数据管理。
增加菜谱时保留旧 id，补齐相同字段及独立图片，同步 asset-manifest.json，再递增 sw.js 的 VERSION。
搜索、分类数量、收藏、食材匹配、采购和离线图片清单均使用数据驱动，不将 40 作为上限。

临时脚本、测试备份、日志和过期截图在修改验证完成后自动清理，规则保存在 AGENTS.md。

字标使用本地 Pinyon Script 书法字体，断网可用；许可证和 FONTLOG 保存在 assets/fonts。
字体来源：https://github.com/google/fonts/tree/main/ofl/pinyonscript

以 320–430 CSS 像素手机视口验证分类、食材状态、采购管理、烹饪步骤和离线资源；更新验证覆盖个人数据保留与烹饪中不强制刷新。浏览器模拟不等于真实 iPhone 验证。
