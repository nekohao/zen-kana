# AUTOSAR BSW PWA 部署

把本目录下所有文件和 `icons/` 文件夹原样上传到 GitHub Pages 仓库根目录：

- index.html
- manifest.webmanifest
- sw.js
- icons/

当前版本：2026.09.29.5

iPhone 更新/安装：
1. GitHub Pages 部署完成后，先在 Safari 打开网页并刷新一次。
2. 如果桌面已有旧版图标，请删除旧图标。
3. Safari → 分享 → 添加到主屏幕。
4. 从新图标启动。manifest 的 display=standalone，会以独立 Web App 打开。
