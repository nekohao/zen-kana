发布页面由源码生成；请编辑 `index.source.html` 和各模块文件，不直接修改 `index.html`。

生成新版：

```sh
node points/build.mjs
node points/tests/shell.test.mjs
```

脚本以北京时间生成日期版本，同一天自动递增序号，并同步写入页面、服务工作线程和 `version.json`。发布时必须同时提交三个产物，避免版本文件和实际页面不一致。

需要复现既有版本时：

```sh
node points/build.mjs 20261008.9 2026-10-08T13:15:31.629Z
```

页面包含全部启动 JS/CSS，首屏不再等待单独的 14 个文件。业务源码仍保留为独立文件便于维护。发布页原始约 876 KB，gzip 约 209 KB；实际传输是否压缩取决于托管服务器。

首次成功打开后，服务工作线程缓存公共应用界面和已查看的菜图。后续打开优先使用界面缓存，实时业务数据仍直接从 Supabase 同步。版本检查只请求小型 `version.json`；发现新版后验证新版 HTML 并自动强制刷新，包括填写或操作期间。刷新前保存厨房草稿，不自动重放业务写入；页面分发尚未完成或下载失败时自动重试，不循环刷新旧版。缓存不包含 API、账户响应、SQL 或测试文件。

iPhone 主屏幕模式使用普通状态栏配置及独立的 `100vh` 画布，底栏按钮区为 52px，系统手势安全区只计一次。桌面手机尺寸预览不能验证 iOS 系统状态栏行为，必须在 iPhone 主屏幕模式复核。

若已经安装的 iOS 主屏幕入口仍沿用旧状态栏配置，先确认页面版本已更新；必要时移除主屏幕图标，再从 Safari 添加新入口。仅移除图标，不清除网站数据。
