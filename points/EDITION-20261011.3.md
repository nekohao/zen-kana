# 20261011.3 直观减脂总览

- 总览收为「体重变化」「结算记录」两个视图。
- 体重变化突出相对起始体重的累计变化，下方展示近七天均重变化及趋势图。
- 趋势时间范围使用紧凑选择器；每日记录移至底部按需展开，原查看和管理能力保留。
- 结算记录直接展示周期、均重变化、实际钻石；点击一行可查看计算依据和结算后余额。
- 未结算的本周预计单独显示，不混入实际记录；未达标显示待达标，不伪造到账数值。
- 结算说明与最近动态放在记录下方，默认折叠。
- 不展示实际体重，保留管理员/游客权限及原有结算算法。本次无 SQL 修改。
